# Portafolio | Ingrid Hernández

Portafolio profesional bilingüe de **Ingrid Hernández**, estudiante de Ingeniería en Sistemas Computacionales en el Instituto Tecnológico de Pachuca, con enfoque en desarrollo backend. Presenta proyectos, tecnologías y medios de contacto en un sitio web de una sola página.

## Proyectos destacados

- **API de movimientos vehiculares:** API desarrollada con FastAPI, SQLAlchemy y MySQL.
- **Gestión de usuarios:** sistema con ASP.NET Web API, ASP.NET Web Forms y MySQL.
- **FIKA-CINEMA:** plataforma web de cine desarrollada en equipo con Angular y Supabase.
- **Control de montacargas:** prototipo con ESP8266, registros 74HC595 y optoacopladores.

## Tecnologías del sitio

HTML, CSS y JavaScript. No requiere dependencias ni proceso de compilación.

El envío debe probarse desde GitHub Pages o un servidor local; abrir `index.html` directamente no permite comprobarlo.
